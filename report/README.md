# Paper drafts (local)

This directory holds LaTeX drafts and is **gitignored** except this README
(not part of the code/data artifact).

| Path | Role |
|------|------|
| **`aaai/`** | **Canonical submission** — `securing_llms.tex` (AAAI 2027) |
| `neurips/` | Older NeurIPS-format draft; do not cite for current numbers |

Figures for the AAAI draft: `aaai/images/` (regenerate with
`python scripts/generate_paper_figures.py`).

Paper **numbers** live in the repo artifact:
`results/loo_matched_fpr/PAPER_TABLES.md` via `python scripts/run_paper.py`.
